Last Minute Project

Last Minute Project is a full-stack digital marketplace designed specifically for college students. It allows users to upload, browse, purchase, and download academic and final year projects across different domains such as web development, AI, cybersecurity, and software engineering.
The platform ensures secure transactions, verified project listings, and an easy-to-use interface for both buyers and sellers.

🎯 Problem It Solves
• Students struggle to find quality final year projects
• No trusted platform for project buying/selling
• Manual sharing causes plagiarism & payment issues

Technologies Used

Node React.js Express MongoDB Next.js API Integration (Razorpay/Stripe) JWT
